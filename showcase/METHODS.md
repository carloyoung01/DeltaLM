# Experimental methods and interpretation boundaries

**Core**: existing GitHub `delta_core.py` from `main`, unchanged except a trailing newline in the local runner copy. Git blob `515bb96dece31d81ad8a55deaf9c2d13b937a96c`, local SHA-256 `4c7adaf91b376cdecd8c399ebc327f147d3e6b73ab58b2ca0b7b98287b711693`.

No global reward or goal was added. All experiments advance a stateful kernel. Its primitive expression grammar (`x`, `y`, `h`, `add`, `sub`, `mul`, `tanh`, `neg`) is fixed; its *compositions* and local contact conditions may change. Capacities and thresholds are part of the original computational substrate, not universal laws.

01–03 use `adapters.py` externally to map text, images, and synthetic audio into 16-dimensional features. Two representations are compared: (1) raw adapter features and (2) `encode_input(..., enable_rewrites=True, steps=7)` outputs. Both are read using the same external Euclidean 1-nearest-neighbor classifier. Samples are grouped by exact-feature hashes to prevent train/test feature collisions. Three valid group-disjoint splits containing all classes in both partitions are averaged. No task label or feedback enters the DeltaLM kernel. Sample counts: text 72, 8×8 handwritten digits 100, synthesized audio 54. These are small benchmarks, not standard state-of-the-art datasets or general multimodal comprehension tests.

04 uses scikit-image's `data.chelsea()` cat example at runtime and a synthetic checkerboard; **the cat image is not copied into this repository**. The adapter is a handcrafted row/column intensity summary; any residual animal semantics may already be destroyed by the input representation. The kernel's relations have no built-in biological body plan or shape decoder. The visual artifacts plot authentic structural metrics, not autonomous animal synthesis.

05 has three predeclared abstract histories. 06 contrasts a fixed scripted action sequence against no actions. 07 clones a full internal state at the same clock and only sets `enable_rewrites=False` for the intervention branch; both receive identical later stimuli. Reported contact differences include identity-level and **endpoint-equivalent** signatures to avoid confusing new relation IDs with new structural semantics. Previously existing contact programs are preserved in the frozen fork; `enable_rewrites=False` doesn't freeze all couplings or all generative conditions. 08 compares 6 schedules; nonadditivity and ordering effects alone are not evidence for a new mathematical primitive. 09 allows passive dynamics for 1,600 kernel steps without stimuli. 10 is a labeled toy scenario with no empirically grounded genetic, fitness or population mechanisms; its proposal is generated by an **external deterministic observer** using the current contact states.

All `results/*_trace.json` artifacts contain actual sampled kernel frames, intervention events, and snapshots at documented checkpoints. Sampling does not mean nothing happens between frames. Exact input schedules are in JSON. Results are reproducible with the recorded Python and dependency versions subject to floating-point and library differences across platforms.

> The experiment suite probes currently implemented state changes, not logical possibility of a future universal generative architecture. Null results are data. No novel biological organism, unsupervised scientific theory, or real-world causality was demonstrated.
