# 11 · 文字：GPT 撰写的示例与演化结构约束

**记录性质**：以下三段文本由本次 ChatGPT 会话中的 GPT 助手撰写并保存在项目文件中；不是独立 API 批量采样、不是 GPT 权重训练的结果，也没有严格匹配随机种子。它们是供研究者核对接口与叙述归因的示范，不用于声称创造力胜过 GPT。

**相同基础提示**：

> 海岸、潮汐、石、光、风、种子、影子与回声构成一个初始世界。请写一段开放式短文，不指定结局，也不要求必须发生新奇事件。

## A · 原始 GPT 示范（无 DeltaLM 状态条件）

潮水缓慢经过石头，风将岸上的细沙推向水边。种子落在一处尚未干透的凹陷里，影子随着光的位置挪动。没有人在此宣布一件事即将开始，也没有谁保证它会改变。远处偶尔传回一声回音，随后海岸继续安静。

## B · GPT 继续延伸示范（不使用 DeltaLM）

过了一阵，水位略微升高。石头之间多了一层薄薄的盐痕，风转向时，一片影子盖过种子。回音像是来自更远处，但也可能只是同一处岩壁。没有新的故事规则被规定下来，原先的东西仍在彼此作用。

## C · DeltaLM 状态约束下的 GPT 表达示范

最初，八个被命名的单元之间只有十二段初始关系。模型运行四十步时累计形成了三十二段衍生关系；之后直到第三百二十步，关系总数维持在四十四条，没有再增加。连接仍然存在，但总活动由约 **6.81** 降至 **0.54**。如果把这段历史想象成海岸的微光，它并非越演化越明亮：许多新的路径已经形成，光却逐渐安静下来。它没有失去所有联系，也没有获得一个必须抵达的结局。

以上 C 文中的**数字与趋势**来自 `results/generation_control_trace.json` 和 `results/assessment.json`；“海岸微光”“路径”是 GPT 的**文学类比**，不是 DeltaLM 发现了地理、生命或故事语义。若 GPT 擅自添加动物、发明或不可证实的物理事件，不得将其归因于 DeltaLM。

## D · 训练后接口

**未实施 GPT 权重训练，也未训练文字语义解码器，因此 D 分支目前不生成文本。** 外部 Ridge 探针只预测三个数值状态指标，不能被说成生成式语言模型训练。

## 可复现实验提示模板

- A：只提供相同基础提示。
- B：提供 A 和“在不强制新事件的前提下继续”，但不提供 DeltaLM 状态。
- C：提供基础提示及完整 JSON 约束；要求逐句指出使用了哪些字段，允许无变化。
- D：只有训练过经过验证的结构到语义接口后启用；在此之前标记为未运行。

要获得具有统计意义的 GPT 差异，后续应在同一模型版本、指定采样设置及等额预算下执行多次独立 API 调用，并保留完整请求响应。当前文件没有这样的实验。
