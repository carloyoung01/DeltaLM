# Methods, controls, lineage, and limitations

The baseline is the public `carloyoung01/DeltaLM` `main` `delta_core.py`, with Git blob SHA `515bb96dece31d81ad8a55deaf9c2d13b937a96c` at experiment time. The core is unchanged; this package excludes its duplicate source when uploaded to GitHub.

**Seed and initial structure:** eight experimenter-selected semantic labels and twelve directed relations, intensity and pace drawn deterministically from NumPy RNG seed 10. Core does not infer domain semantics. The labels have no direct causal power except endpoint identity and reproducible initial graph structure.

**Structural trajectories:** 0–320 steps. Single-world tide/reverse/no-extra-stimuli schedules, with four externally supplied impulses; all are identical except the order of those impulses. Initial-state-only videos are static. The *no-extra-stimuli* test still starts with a nonempty 12-relation graph; a separate fully empty world proves zero births after 400 steps.

**Counterfactual:** snapshot at step 160; fork with the same continuation and timing; set `Substrate.enable_rewrites=False` in the intervention. This is externally controlled. `contact_rewrites` in frozen branch includes changes from BEFORE freezing and is not expected to be zero. Relation signature difference zero in all three new short-horizon forks, despite changes in coupling; a null structural comparison is explicitly reported. Do not confuse observable contact-condition differences with a proof that all mathematically reachable states changed.

**External readout:** image nodes use researcher-assigned polar positions perturbed by actual `lenses`; each line represents the current relation endpoint/weight. Audio converts current `activity_abs`, `n_relations`, and `mean_coupling` into amplitudes and frequencies with a fixed formula. Video is a frame replay of the images. These are demonstrative, not meaningful domain semantics automatically discovered by core.

**Training:** 32 independent initial worlds, 7 examples per world, with distinct seeds and random but fixed intervention schedules. 24 entire worlds to train and 8 disjoint worlds to test. Inputs are ten present-state numeric summaries. Targets are relation count, activity absolute sum and mean coupling five steps later; no intervention inside the 5-step target interval. Ridge alpha=4 with train-only StandardScaler. Compare a persistence predictor. Model scaler and coefficients are serialized into JSON. This tests an external trainable probe of state; it **does not** change DeltaLM parameters or test cross-domain semantic transfer.

**GPT sample:** the text A/B/C files are written by the ChatGPT assistant in this session and not automatically generated by a controlled repeatable GPT API runner. Independent GPT image/audio/video inference and all GPT weight training are absent. The source-specific illustrations generated by image tools in the chat, if any, are not included as structural evidence. No model improvement is claimed.

**Reproducibility:** Python 3.11+ preferred, `numpy`, `scikit-learn`, `Pillow`, ffmpeg with libx264. `OPENBLAS_NUM_THREADS=1 python ...` for reproducible numerical probe; minor float variations expected. Media images/videos are rendered from trace data with stable layout; video codec output may differ across ffmpeg builds. See `SHA256SUMS.txt` for the exact distributed files.

**Independent result checker:** `python -m unittest integrations/open_generation/test_integrity.py -v` (in repo) or `python -m unittest test_integrity.py -v` (in extracted evidence work directory).
